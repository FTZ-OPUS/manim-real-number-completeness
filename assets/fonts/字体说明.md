# 字体说明（跨平台楷体方案）

全片气质依赖一套楷体系字体。场景代码中字体只是一个字符串常量（`ZH_FONT`），
换机器时用 style-guide §2 的检测片段自动回退，或按下表手动安装后改常量。

## 各平台推荐

| 平台 | 字体名（代码里的字符串） | 来源 |
|---|---|---|
| macOS | `Kaiti SC` | 系统自带（样板间默认） |
| Windows | `KaiTi`（楷体） 或 `楷体` | 系统自带 |
| Linux | `AR PL UKai CN` | `sudo apt install fonts-arphic-ukai` |
| Linux / 全平台推荐 | `LXGW WenKai`（霞鹜文楷） | 开源 OFL 协议，https://github.com/lxgw/LxgwWenKai/releases 下载 TTF 后双击安装 |

## 检测脚本（放进场景文件顶部，自动回退）

```python
from matplotlib import font_manager   # manim 依赖 matplotlib，无需额外安装
_installed = {f.name for f in font_manager.fontManager.ttflist}
ZH_FONT = next((n for n in ["Kaiti SC", "STKaiti", "KaiTi", "楷体",
                            "AR PL UKai CN", "LXGW WenKai", "Noto Serif CJK SC"]
                if n in _installed), "Kaiti SC")
```

> 注意：`Kaiti SC` 是苹果授权字体，**禁止**随 skill 分发字体文件本身；
> 跨机器统一观感请统一安装开源的霞鹜文楷，并把 `ZH_FONT` 设为 `LXGW WenKai`。

## 排版影响提示

- 不同楷体字重量略有差异，换字体后全片抽帧复查一次（重点：标题是否触边、公式行是否过宽）。
- `Text()` 走 Pango，缺字会静默回退到系统字体（可能混入黑体），发现混字就换字体或换写法。
