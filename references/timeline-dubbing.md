# 配音方法论：源码重建时间轴 → 逐句音画同步

> 目标：**每句话说到什么，画面就演到什么**。方法论在 26 段样板间上全绿验证（时长误差 0.00s）。

## 1. 铁律：先找渲染源码，绝不靠读帧建段落表

段落结构一目了然的来源是场景 `.py`：每个 `construct` = 一幕，`title_bar("...")` = 段名。
**段落顺序以 `construct()` 里的调用顺序为准，不是方法定义顺序**。

## 2. 从源码累加时间轴（纯算术 + 硬自检）

逐段累加每个 `self.play(..., run_time=X)` 与 `self.wait(T)`：

- 无 `run_time` 的 `play` 记 **1.0s**（多动画混合取最大值；`Flash` 默认 1.0s）。
- `clear_scene()` = 0.6s，别漏。
- 3D 场景的 `move_camera(run_time=0.1)`、`begin_ambient_camera_rotation` 也要核对。

**硬自检**：全片累加总和必须 ≈ `ffprobe` 实际时长（误差 ≤0.5s）。
样板间成绩：源码累加 144.1s = 实测 144.1s，且每一幕分毫吻合——因为总时长由每幕构成，逐幕都对上则段内累加被强制成立。

**对不上时 ≠ 推倒重来，也不许线性缩放**：漂移往往集中在少数几段的收尾 `wait`。标准动作：

1. 按「模型边界 + 0.4s」抽**单张全分辨率帧**：标题正在写一半 → 边界正确；上一段完整保持态 → 实际更晚；已进下一段 → 更早。
2. 只修有漂移的几段，其后边界整体平移，用后续探针验证平移量，直到首、中、尾三点帧证据闭合。

```bash
# 抽探针帧
ffmpeg -ss 6.2 -i 母带.mp4 -frames:v 1 /tmp/probe_6.2.png
# 批量时长
ffprobe -v error -show_entries format=duration -of csv=p=0 文件.mp4
```

## 3. 段落切分粒度

- 一幕 30~90s → 切 1~4 段，切在**视觉节拍**上（新的图形元素出现的时刻）。
- 每段 9~30 字最佳；短段（<8 字）听感急促，宁并勿拆。
- 样板间：144s 切 26 段，段均 5.5s。

## 4. 配音文案预算（实测校准）

- 本机 edge-tts `zh-CN-XiaoyiNeural` 实测语速 ≈ **4.6 字/s @ +4%**（比经验值 5.0 慢）。
- 每段字数预算 ≈ `(段长 − 0.7s) × 4.6`；0.7s = 起播提前量 + 呼吸。
- 幽默风趣**但严格对应画面**：段落表里写什么，屏幕上演什么；数字、颜色、定理名必须与画面一致。
- 管线内置首尾静音裁剪，超长自动 +4% 递进到 +24%，仍超长会打印「建议删 N 字」——**先改文案，不要让级联错位**。

## 5. config 与管线

```json
{ "project_dir": "...", "video": "母带.mp4", "out_name": "成片.mp4",
  "voice": "zh-CN-XiaoyiNeural",
  "sections": [ {"name": "...", "start": 0.0, "end": 5.8, "text": "文案"} ] }
```

```bash
python scripts/dub_pipeline.py work/dub_config.json
```

管线做的事：分段 TTS（网络重试 5 次指数退避 + 首尾静音裁剪 + **文案哈希缓存**，改一段只重配一段）
→ 级联排程 `start_i = max(段首+0.3, 前段结束+0.25)` → ffmpeg `adelay|amix` 混流（视频流 `-c copy` 直拷）
→ 验收（时长一致 + 等间隔响度抽点）→ 输出 `out/段落表.txt` 与 `work/audio/manifest.json`。

排程健康信号：**所有段都等于 段首+0.3**，出现顺延即文案超长。

## 6. 自备录音替换法（客户自己配音）

1. 跑一次管线后打开 `work/audio/manifest.json`：`段名 → tts_<哈希>.mp3`。
2. 把自己的录音（wav/mp3 均可）**覆盖保存为对应哈希文件名**，时长尽量 ≈ 原段长 − 0.7s。
3. 重跑管线：该段识别为「缓存命中」直接采用，其余段不受影响，排程自动重算。
4. 录音明显偏长时，后段会顺延——要么剪短录音，要么在 config 里加大该段 `end`（需相应改画面 hold，回源码同步）。

## 7. 验收硬标准（verify_film.py 自动执行）

| 指标 | 标准 |
|---|---|
| 成片时长 | = 母带时长 ± 0.5s |
| 音轨存在 | 必须有 audio 流 |
| 响度抽点 | 说话区 -20 ~ -30dB；**< -55dB = 死气段**，回炉加文案重配 |
| 探针帧 | 每个关键段边界抽 1 帧，人眼/视觉裁判确认音画对位 |
| 段落表 | `out/段落表.txt` 随片交付，客户可逐段微调 |
